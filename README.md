# Sayidan Yaziya

Girilen sayiyi Turkce yaziya cevirmek icin hazirlanmis bir C# konsol uygulamasi. Donusturme mantigi sayiyi basamak gruplarina ayirir ve her grubu Turkce olarak yazar.

## Gereksinimler

- .NET 10 SDK

## Calistirma

Proje dizininde asagidaki komutu calistirin:

```bash
dotnet run
```

Mevcut program `Program.cs` icindeki `Main` metodunda sabit olarak tanimlanan `1221222` degerini donusturur. Ornek cikti:

```text
bir milyon iki yuz yirmi bir bin iki yuz yirmi iki
```

Farkli bir deger denemek icin `Main` metodundaki sayiyi degistirin. Su anki uygulama konsoldan kullanici girdisi almaz.
